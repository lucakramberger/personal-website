# Website-Entwürfe

Zwei Design-Richtungen für kramberger.studio. Stand: November 2026.

Zum Ansehen `uebersicht.html` im Browser öffnen.

## Variante A — Persönlich & editorial

Warmes Papier (#F4EFE6), Serifenschrift Fraunces, Kobaltblau (#1E3BC8) als einziger Akzent.
Das Porträt trägt die Startseite, Abschnitte werden durch Haarlinien getrennt.

- `A-desktop.html` — Startseite, 1440 px
- `A-mobil.html` — Startseite, 390 px
- `A-stil.html` — Farben, Schriften, Bausteine

## Variante B — Bunt & mutig

Tiefschwarz (#0D0A14) als Bühne, flache Farbflächen in Limette (#D6FF3D), Violett (#7B3DFF)
und Magenta (#FF2E88). Bricolage Grotesque, dicke Rahmen, harte Schatten.

- `B-desktop.html` — Startseite, 1440 px
- `B-mobil.html` — Startseite, 390 px
- `B-stil.html` — Farben, Schriften, Bausteine

## Ordner

- `luca.jpg` — Porträt, auf 1400 px verkleinert
- `canvas-quelle/` — Originaldateien der Design-Leinwand (`.dc.html` + `canvas.json`).
  Nur dort läuft die einstellbare Akzentfarbe; in den exportierten Dateien steht Kobalt fest drin.
